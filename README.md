# Calculator

A functional calculator built with HTML, CSS, and JavaScript as part of a JavaScript learning project.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Chained calculations
- Decimal number support
- Positive and negative number toggle
- Percentage calculations
- Backspace and clear functions
- Keyboard support
- Division-by-zero error handling
- Rounded results to avoid unnecessarily long decimal values
- Responsive calculator interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Use the on-screen buttons or keyboard to perform calculations.
